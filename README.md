# TYT Bulk Manager

Userscript hỗ trợ quản lý truyện và chương trên TYT Novel.

## Chức năng

- Nhập và đăng chương từ TXT.
- Tách file TXT tổng hợp thành từng chương.
- Xuất nội dung chương ra TXT.
- Cập nhật nội dung chương hàng loạt.
- Đổi tên và đánh số lại chương.
- Xóa chương đã chọn.
- Thống kê doanh thu và dữ liệu liên quan.
- Lưu cấu hình sử dụng trong trình quản lý userscript.

## Cài đặt

1. Cài [Tampermonkey](https://www.tampermonkey.net/) hoặc Violentmonkey.
2. Mở liên kết cài đặt:

   [Cài TYT Bulk Manager](https://raw.githubusercontent.com/caccac11/TYT-Bulk-Manager/main/tyt-bulk-manager.user.js)

3. Nhấn `Install` hoặc `Cài đặt`.
4. Đăng nhập TYT Novel.
5. Mở trang `https://tytnovel.info/`.

## Cảnh báo

Script thao tác trực tiếp trên dữ liệu của tài khoản TYT đang đăng nhập.

Hãy sao lưu nội dung trước khi:

- cập nhật hàng loạt;
- đánh số lại;
- đổi tên hàng loạt;
- xóa chương.

Việc xóa chương có thể không hoàn tác được. Giao diện hoặc endpoint của TYT thay đổi cũng có thể khiến một số chức năng ngừng hoạt động.

## Báo lỗi

Mở mục [Issues](https://github.com/caccac11/TYT-Bulk-Manager/issues) và cung cấp:

- phiên bản script;
- chức năng đang sử dụng;
- nội dung nhật ký hoạt động;
- ảnh lỗi nếu có;
- không đăng cookie, mật khẩu hoặc thông tin đăng nhập.
